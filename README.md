
# Student Performance Management System

A Python-based Student Performance Management System for managing student records, marks, grades and class statistics.

## Project Description

This is a command-line Python application designed to store and manage student academic information. It allows the user to add, view, search, update and delete student records. The system also calculates student averages, grades, pass/fail results and class statistics.

Student data is stored in a JSON file so that records can be retained when the program is closed and opened again.

## Features

- Add a new student
- View all student records
- Search for a student using Student ID
- Update student information and marks
- Delete a student record
- Calculate average marks
- Calculate grades
- Display pass/fail result
- Find the top performer
- Display class statistics
- Store data using JSON
- Input validation for marks and semester

## Requirements

- Python 3.x
- No external Python packages are required.
- The project uses Python's built-in `json` module.
